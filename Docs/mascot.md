# 吉祥物放置

Pocket Note 的吉祥物是一隻紫色 Q 版貓耳角色。配色與介面的 `#FAF8FF`、`#E9D5FF`、`#7C3AED` 一致。每種樣式只服務一個位置。

全身像留給空的、居中的畫面。列表、按鍵和種類用簡化的頭像加一件道具。小尺寸裡裙子和尾巴會糊成一團，種類也認不出來。

## 全身或半身

這些位置是空的，而且一次只出現一個角色。有資料時全身像離開，列表和圖表保持乾淨。

| 樣式 | 位置 | 說明 |
| --- | --- | --- |
| 站立打招呼 | 開場畫面 | 放在軟件名稱上方，背景 `#FAF8FF`。載入完成後進入預設模塊 |
| 同一張站立像，稍小 | 鎖畫面 | 放在「Pocket Note」與密碼欄之間 |
| 抱著清單、往旁邊看 | 待辦空狀態 | 文字為「目前沒有任務」。寬度約為螢幕的一半，圖在文字上面 |
| 捧著錢包 | 記帳空狀態 | 「這個範圍沒有交易」，以及報表的「這段期間沒有可顯示的收支」 |
| 坐著寫字 | 備忘錄空狀態 | 「目前沒有備忘錄」 |
| 趴在空箱子旁 | 垃圾桶空狀態 | 「垃圾桶是空的」 |
| 舉手慶祝 | 連續打卡 | 待辦統計頁的連續打卡卡片。今天的任務全部完成時，也可出現在日曆列表底部 |
| 輕輕抱著帳單、表情擔心 | 預算超支 | 只在超支時出現在預算卡片角落 |

搜尋沒有結果時，沿用該模塊的空狀態圖並縮小，不必再畫新的一張。

## 只有頭和肩膀

側邊欄和設置頁的寬度不夠放全身。

| 樣式 | 位置 |
| --- | --- |
| 平常表情 | 側邊欄軟件名稱旁邊 |
| 平常表情 | 設置頁標題下方 |
| 眨眼 | 備份或還原成功後，在設置頁出現一下，然後回到平常表情 |

## 種類圖示

支出、收入、帳戶和待辦分類可以換成吉祥物。做成另一套小圖：圓形頭像，手裡或頭上只留一件道具，線條比全身像少。按 24–32px 來畫，先縮小檢查道具是否還認得出來。

這些小圖用在記一筆的分類格、流水每一行的左側、報表圖例，以及任務卡片的最左邊。

### 支出

餐飲、交通、居住、賬單、購物、娛樂、醫療、教育、人情、金融、個人護理、其他。

### 收入

薪金、兼職、獎金、投資、利息、禮物、其他。只在收入分類裡出現。

### 帳戶

現金、銀行卡、信用卡、電子錢包。用在帳戶頁每一行。

### 交易

支出、收入、轉帳、退款。

轉帳和退款沒有分類時用這兩枚。支出和收入的那一行仍用上面的分類圖示。

### 待辦

工作、個人、購物、其他。用在任務卡片最左邊。

優先級繼續只用淡紅、淡橙、淡藍。重複和看板保持簡單符號，不畫成角色。

## 按鍵

只改右下角的建立按鈕。圓形底保持現有樣式，中間的加號改成爪印，或一個很小的頭加上加號。記帳、待辦、備忘錄用同一顆。

返回、關閉、儲存、刪除、篩選、排序保持普通圖示，讓人一眼看出動作。

## 不要放置的位置

- 流水和任務列表的卡片裡，分類小圖之外不要再疊一隻全身像。
- 金額鍵盤、日曆格子、圓餅圖中間。
- 右下角建立按鈕的旁邊。全身像的尾巴會蓋住這個按鈕。
- 「記這一筆嗎」、刪除確認、還原覆蓋這一類對話框。這些畫面要讓人看清選項。

### **PocketNote** 一個關照你生活方方面面的軟件
特點：記賬、TODO-List、備忘錄、本地儲存、google硬碟儲存

無中心服務器、本地優先、下載即用、用戶自備google drive

## 記賬：

1. 記帳錄入
- 快速記一筆：金額、日期、收支類型、分類、備註
- 多種輸入方式：email識別電子賬單、拍照識別發票/收據（OCR）
- 自訂分類與子分類（餐飲、交通、房租…）
- 支援多帳戶（現金、信用卡、銀行卡、電子錢包）

2. 帳目管理
- 編輯、刪除、搜尋、篩選交易
- 按月/週/年查看流水
- 轉帳功能（帳戶之間移動，不計入收支）
- 退款/沖銷處理

3. 統計與報表
- 收支總覽（本月收入、支出、結餘）
- 分類圓餅圖、趨勢折線圖
- 月度/年度對比
- 預算 vs 實際花費

4. 預算管理
- 設定總預算與分類預算
- 超支提醒
- 預算進度條

5. 資料安全
- 本地儲存 + 雲端同步（用戶自己的email google雲端）
- 密碼/生物辨識鎖
- 匯出備份（CSV、Excel、JSON）

## TODO-List:
- 新增任務：輸入標題即可建立待辦事項
- 編輯任務：修改標題、描述
- 刪除任務：單筆刪除/多筆刪除
- 子任務：一個任務拆成多個步驟
- 重複任務: 每天 / 每週 / 每月自動重置

- 標記完成 / 未完成：勾選框切換狀態
- 任務列表顯示：清楚列出所有任務
- 截止日期 / 時間：設定 due date，可排序
- 優先級：高 / 中 / 低，或用顏色標示
- 分類 / 標籤：工作、個人、購物等
- 備註 / 描述：任務的詳細說明
- 篩選：全部 / 未完成 / 已完成 / 今日到期
- 排序：按日期、優先級、建立時間

- 提醒通知: 到期前推送
- 拖拽排序: 手動調整順序
- 日曆檢視: 用月曆看任務分佈
- 看板檢視: 待辦 / 進行中 / 完成

- 統計：完成率、連續打卡天數

## 備忘錄：
- 新增 / 編輯 / 刪除備忘錄
- 每個備忘錄擁有標題+內容
- 自動儲存
- 備忘錄列表
- 關鍵字搜尋備忘錄標題
- 刪除垃圾桶，保存刪除的備忘錄30天，30天后自動清除，可復原
- 釘選和置頂
- 分類/標籤
- 排序
- 字數統計
- 多選刪除
